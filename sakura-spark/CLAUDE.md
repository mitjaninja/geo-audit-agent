# CLAUDE.md

Проект: Sakura Spark — match-3 в аниме-стиле, Telegram Mini App. Требования — PRD.md, план — ROADMAP.md.

## Правила
- Node 20+, TypeScript strict, ESM. Тесты — node:test через tsx, лежат в `test/` пакета.
- `packages/core` — чистая логика: без DOM, сети, движка, `Math.random` и `Date`. Вся случайность — через `Rng` с сидом.
- Детерминизм — контракт: сид + ходы → тот же результат. Сервер проигрывает реплеи тем же ядром.
- Ядро не анимирует, а отдаёт события (матч, падение, досыпка, перемешивание); клиент их рисует.
- `apps/client` не дублирует правила игры: только рисует события ядра и шлёт ходы. Чистая логика клиента (раскладка, ввод, тема) — в модулях без Phaser, с тестами.
- Изменения клиента проверять `npm run smoke` и смотреть скриншоты.
- Названия и тексты оригинальные: никаких Candy, Saga и персонажей чужих тайтлов.
- Один этап из ROADMAP.md — одна сессия. Перед завершением: npm run typecheck && npm test.

## Команды
- npm test · npm run typecheck · npm run dev · npm run smoke · npm run autotest
